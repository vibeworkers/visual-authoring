# Concept Map

## Path 1: 문제 진단 경로
현황 CSS 스캔 -> 하드코딩 분포 파악 -> 병목 1문장 고정

## Path 2: 토큰 통합 경로
역할 분류(배경/텍스트/상태) -> `--cds-*` 토큰 매핑 -> alias 연결

## Path 3: 레이아웃 정렬 경로
히어로 의도 정의 -> 섹션별 job 1개 고정 -> 카드/그리드 위계 정리

## Path 4: 검증 경로
desktop 캡처 -> mobile 캡처 -> PASS/CONDITIONAL/FAIL 판정

## Path 5: 종료 경로
Must 점수 산정 -> 잔여 갭 정리 -> 다음 액션 1줄 확정
