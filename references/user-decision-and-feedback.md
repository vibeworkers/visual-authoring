# User Decision, Comparative Preview, and Feedback Guide

## Decision packet contract

사용자 결정은 다음 순서로 남긴다. 목표·청중·산출물·성공 조건·확인자를 먼저 기록한다. 원본이나 이전 작업이 있으면 `continue_improve` 또는 `fresh_start`를 명시적으로 선택받는다. 없는 경우만 `not_applicable_no_existing_work`로 닫는다.

모든 응답은 아래처럼 Step by Step으로 현재 위치를 보인다.

```text
진행 상황  [████░░░░░░] 2/6
현재 단계  Step 2/6 — Review Gate
이번에 확인한 것  <관찰·근거>
사용자 결정  <선택 필요 / 없음>
다음 단계  Step 3/6 — 전략·표현·매체 선택
```

공통 단계는 `phase_0`부터 `phase_5`까지다. 건너뛴 단계는 `skipped + 이유`로 남기며, 닫은 단계만 진행바에 채운다. 진행률은 작업 순서만 말하며 품질, 접근성, 사람의 이해·행동 변화, 릴리즈 승인을 뜻하지 않는다.

안정 schema 이름은 `visual-authoring.decision-preview.v1`이다. 상세 구조는 `scripts/validate_visual_authoring_decision_packet.py`가 검사한다.

## Comparative preview rules

열려 있는 전략 축은 최소 두 후보를 만든다. 각 후보는 다음 두 증거를 함께 낸다.

1. `image_generated` 시각 콘셉트 이미지: 장면과 톤을 빠르게 비교한다.
2. 목표 매체 전체를 대표하는 target-surface render: 실제 정보 구조와 행동 표면을 비교한다.

부분 카드, 색상칩, 무관한 무드보드는 두 번째 증거를 대신하지 않는다. UI는 기본·행동·상태/오류·데이터/읽기 표면 등 `required_surface_ids`를 먼저 정하고 각 후보가 같은 범위를 덮어야 한다. 슬라이드는 대표적인 시작·핵심 판단·마무리 장면의 읽기 흐름을, 문서는 읽기·탐색·행동 표면을 함께 보여 준다. preview를 만들 수 없으면 `blocked_preview_generation`으로 남기고 선택을 가장하지 않는다.

색상 후보도 같은 완전한 표면 범위를 사용한다. 비교 전에 아래를 평이한 질문으로 안내한다.

- 어느 화면에서 중요한 행동이나 다음 단계를 가장 빨리 찾을 수 있는가?
- 일반·주의·오류 상태를 색만 보지 않아도 구분할 수 있는가?
- 실제 사용 크기에서 본문·숫자·버튼을 편하게 읽을 수 있는가?
- 강조가 우선순위를 돕고, 필요한 톤과 충돌하지 않는가?

이 질문은 대비, 가독성, 주의 계층, 상태 의미, 색각 다양성, 정서적 톤을 사용자가 비교할 수 있게 풀어 쓴 것이다. 자동 accessibility pass나 사람 선호의 증거는 아니다.

## Release credit decision

릴리즈 직전 `include_author_credit`, `omit_author_credit`, `custom_credit` 중 하나를 명시적으로 확인한다. `custom_credit`에는 표기 문구와 위치가 필요하다. 모델·도구 provider, source provenance, output brand는 저자 표기와 다른 필드이며 자동 변환하지 않는다.

## Future human-feedback question bank

기본값은 `human_feedback.mode: off`다. 이 상태에서는 아래 문항을 제공만 하며 수집·점수화·판정하지 않는다. 사용자가 나중에 `on`을 명시하면 대상, 동의, 수집 채널, 보관 정책, 중단 조건을 먼저 정한다.

7점 리커트 척도: 1=전혀 그렇지 않다, 4=보통이다, 7=매우 그렇다.

1. 이 자료가 내가 무엇을 알아차리거나 해야 하는지 분명히 보여 주었다.
2. 정보의 순서가 다음 내용을 따라가기 쉽게 만들었다.
3. 문구·시각 요소·색상이 서로 헷갈리지 않고 함께 읽혔다.
4. 중요한 행동이나 결정 지점을 쉽게 찾을 수 있었다.
5. 한 번에 처리해야 할 정보량이 감당할 만했다.
6. 일반·주의·오류 상태를 색에만 기대지 않고 구분할 수 있었다.
7. 저자·출처 정보가 분명하고 적절했다.
8. 이 자료를 본 뒤 무엇을 할지 알 수 있었다.

자유응답은 “가장 도움이 된 화면/장면과 이유”, “헷갈리거나 멈춘 지점”, “다음 버전에서 바꾸면 좋을 한 가지”를 사용한다. 이 결과는 특정 사용 조건의 피드백일 뿐, 진단·학습·행동 변화·일반적 효과를 자동으로 증명하지 않는다.
