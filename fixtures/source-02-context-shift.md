# 맥락 연결과 관점 이동

이 문서는 현재 대화와 접근 가능한 로컬 기록을 바탕으로 다시 쓴 관찰용 문서다. 원문 대화의 직접 인용이 아니다.

처음의 세 파일은 자리표시자로 읽혔지만, 로컬 visual-authoring 자료는 관찰·코퍼스 해석·대상 표면 이식을 분리하고, `inference goal → visible cue → reading path → action`의 흐름을 요구한다. 또 다른 시나리오 자료는 사실, 조건부 가정, 현장 검증 필요 항목을 나눈다. 이 맥락을 연결하자 파일 이름을 바꾸는 일은 장식이 아니라 출처 경계와 다음 검증 행동을 보이게 하는 작업으로 이동했다.
