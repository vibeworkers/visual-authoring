# Visual Authoring Identity

## Purpose

Visuals made to represent this skill should make its work legible: turning a
messy source into an intentional visual artifact, checking that artifact, and
returning the decision to a person. They are not generic AI imagery.

## Primary profile mark — Framed Loop Mark

Use this as the default direction for a square profile image, favicon, and
small social avatar.

1. A stable square frame represents the authored system and evidence boundary.
2. A small grid becoming fewer, clearer forms represents source decomposition
   and visual authoring.
3. A restrained circular or orbiting line represents the review and repair
   loop.
4. A single simplified human hand or fingertip at the edge represents human
   judgment and release authority.

The mark must remain identifiable at 48 px. It should contain no text, no
product-interface screenshot, and no more than four semantic elements.

## Why this direction is primary

It integrates the six core ideas already used in the skill's symbol study:
frame, source grid, transformation, verification, return loop, and human
judgment. The relationship reads from left-to-right or center-to-edge without
claiming that the system autonomously makes the final decision.

## Generation brief

```
Square profile icon for “Visual Authoring”: a precise editorial emblem, not a
generic AI logo. A calm square frame holds a small structured grid that resolves
into 2–3 clear geometric forms. A thin verification orbit partially circles the
frame. At one edge, a minimal human fingertip makes one deliberate contact with
the frame. Flat vector-like forms, high silhouette clarity, no text, no letters,
no gradients that blur at small size, no chatbot face, no paintbrush, no lightbulb,
no brand logos. Leave a safe margin around the emblem. Use an intentional palette
only after the color comparison gate; supply monochrome first if no palette is
selected.
```
