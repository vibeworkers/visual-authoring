# Visual Authoring Symbol

- **파일**: `visual-authoring-symbol.png`
- **용도**: Visual Authoring 프로젝트의 README, 프로필, 저장소 대표 이미지
- **제공 시점**: 2026-07-26
- **출처**: 프로젝트 소유자가 이 작업에서 제공한 생성 이미지
- **의미**: 원본 조각 → 정돈된 시각 형식 → 장면화, 검토 궤적, 사람의 최종 승인

생성 모델, 프롬프트, 제3자 입력물, 별도 사용권은 이 저장소에 제공되지 않았다. 따라서 이 파일을 저장소 밖에서 재사용하거나 별도 라이선스를 부여하기 전에는 권리 조건을 확인해야 한다.
