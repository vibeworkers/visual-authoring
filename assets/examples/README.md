# 실제 결과 사례 자산

이 폴더는 Visual Authoring이 실제 저작 과업에서 만든 결과물 중, 공개 저장소에서 소개할 수 있는 장면만 발췌해 둔 곳입니다. 원 프로젝트 전체나 그 프로젝트가 다룬 모든 자료를 재배포하는 폴더는 아닙니다.

## 선정 기준

- 하나의 내용을 반복 카드가 아니라 서로 다른 시각 구조로 읽게 하는가
- 결과물 안에서 주장, 가정, 다음 행동, 검증 경계가 구분되는가
- 저장소 기여자가 권리를 가진 저작물인가
- 화면만으로 학습 효과, 구매, 실제 배포 완료를 과장하지 않는가

## 포함한 자산

| 자산 | 실제 결과물과 역할 | 공개 경계 |
|---|---|---|

`vibeworking-*` 이미지 안에 보이는 Claude 명칭은 Anthropic의 상표입니다. 이 저장소는 Anthropic과 제휴하거나 승인을 받았다고 주장하지 않습니다.

## 재배포하지 않은 사례

PostHog 콘텐츠 행동 분석 시각 가이드는 실제 제품 UI를 근거 화면으로 사용한 12쪽 교육 결과물입니다. 화면의 구성과 한글 설명은 이 방식으로 저작했지만, 제품 UI와 상표의 권리는 각 원권리자에게 있습니다. 따라서 이 저장소에는 그 화면을 넣지 않고, README에서 사례의 저작 방식과 권리 경계만 소개합니다.

## 라이선스와 주장 범위

이 폴더의 위 원저작 발췌는 저장소의 [CC BY-NC 4.0](../../LICENSE) 범위에 포함됩니다. 다만 이미지 안의 상표, 제품 이름, 제3자 자료에는 별도 권리가 남습니다. 어떤 사례도 독자의 이해도, 교육 효과, 실제 구매, 실제 재사용, 외부 배포 완료를 증명하지 않습니다. 그 결과는 해당 맥락의 추가 증거와 사람의 판단이 있어야 말할 수 있습니다.
